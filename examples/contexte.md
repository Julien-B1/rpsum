# Contexte de campagne — modèle

Ce fichier est libre : notes en vrac, listes, extraits, liens. `rpsum` le lit, suit les liens, et en tire une
fiche structurée (`runs/<id>/context.json`). Rien n'est obligatoire. Plus il y a de noms propres, mieux ils
seront écrits dans le transcript et les résumés.

Usage : `rpsum run <url> --context examples/contexte.md`
